Two real UIs broken down the way a frontend engineer reads them — not as one page, but as a tree of responsibilities. Same six-step lens applied to each, kept as two separate trees so the patterns are easy to compare.

Application→ Page→ Layout→ Sections→ Components→ Elements
YouTube Home page · sidebar + top-nav + content layout
Sidebar
Top navigation
Video grid
  • Home page
    • Top navigation
      • HamburgerButton, Logo, SearchBar, SearchButton, VoiceButton, CreateButton, NotificationButton, UserAvatar
    • Sidebar
      • MainNavigation (NavigationItem × N), SubscriptionList, LibraryMenu, FooterLinks
    • Category navigation
      • CategoryChip — repeated, one component, text changes
    • Video grid
      • VideoCard — repeated: Thumbnail, DurationBadge, VideoTitle, ChannelName, VideoMetadata, MenuButton
    • Mini player
      • Thumbnail, Title, ProgressBar, Controls, CloseButton
Zoom in: SearchBar isn't one element — it's TextInput + Placeholder + ClearButton(X) + SearchIcon composed together. Same with Thumbnail: Image + DurationBadge + (optional) ProgressBar.
ChatGPT Chat page · sidebar + content layout
Sidebar
Breadcrumb header
Conversation area
Message composer
  • Chat page
    • Sidebar
      • TabGroup, ChatNavigation, ChatList (ChatItem × N), UserProfile, SidebarFooter
    • Breadcrumb header
      • FolderIcon, WorkspaceName, Separator, ChatTitle
    • Conversation area
      • UserMessage / AssistantMessage — repeated, alternating
    • Message composer
      • TextArea, VoiceButton, AttachmentButton, SendButton
Zoom in: AssistantMessage is Avatar + Markdown + CodeBlock + CopyButton + Actions — and CodeBlock itself nests further into Header + LanguageLabel + CopyButton + CodeContent. Components containing components, all the way down.
