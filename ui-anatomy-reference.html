    <ui-anatomy/>

    A reference sheet of the recurring "body parts" of a web UI: the common page layouts, then every individual element inside them — one explanation of what each does and when to use it, followed by a working HTML/CSS implementation you can lift directly. Each demo is framed like an inspector highlight so the boundaries of the element are obvious.
